Projects

rfc-rag-pipeline

Hybrid Retrieval Engine for IETF RFCs

Retrieval-augmented generation pipeline for technical documents. Dense embeddings and BM25 sparse retrieval fused via Reciprocal Rank Fusion (k=60). Structural chunking follows RFC section boundaries instead of splitting on token count.

  • 64 tests, mypy strict, ruff linting
  • Python library, no HTTP server or daemon
  • Retrieval bias documented via ADR
Private — available on request.

convergence-crdt

Op-Based CRDT for Collaborative Text

RGA (Replicated Growable Array) with causal ordering, out-of-order delivery, and fuzz-tested convergence across N sites. Lamport clocks for total ordering with deterministic tiebreak on site ID.

  • 77 tests including multi-site fuzz convergence
  • Optional WebSocket transport; zero core dependencies
  • SQLite checkpoint persistence; opt-in tombstone GC
Private — available on request.

stockflow

Inventory Management and POS System

Laravel 13 inventory and point-of-sale system for small retail. Computed stock from transaction audit log, atomic checkout, role-based access (admin/cashier), and sales reporting with CSV export.

  • 32 Pest feature tests covering auth, CRUD, POS, inventory, reports, security
  • POS checkout with Alpine.js cart and DB::transaction rollback
  • Security audit passed: rate limiting, server-side pricing, RBAC
Private — available on request.

salary-predictor

ML Salary Prediction with SHAP Explainability

End-to-end ML pipeline: XGBoost regressor (R2=0.976) trained on 6,700 rows, SHAP explanations per prediction, and a FastAPI serving endpoint with Pydantic v2 validation. Model serialized as native .ubj (no pickle).

  • 15 pytest tests: data pipeline, inference, API integration
  • FastAPI lifespan hook for single-load model serving
  • SHAP summary, dependence, and waterfall plots
Private — available on request.
